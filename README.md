# TP3-Blockchain-Bitcoin

Projet individuel sur le fonctionnement des transactions Bitcoin  TP3 - Blockchain
Bitcoin



\## Sujet

Comprendre le fonctionnement d'une transaction Bitcoin : entrées, sorties, frais et confirmations.



\## Problématique

Comment une transaction Bitcoin est-elle créée, vérifiée et confirmée sur la blockchain ?



\## Objectifs

\- Expliquer le fonctionnement d'une transaction Bitcoin.

\- Comprendre le rôle des entrées et des sorties (UTXO).

\- Identifier les frais de transaction.

\- Expliquer le processus de confirmation.



\## Démarche

Ce projet repose sur une étude documentaire et un exemple pédagogique de transaction Bitcoin. L'analyse présente les principales étapes d'une transaction, de sa création à sa confirmation.



\## Résultat attendu

Une analyse illustrée permettant de comprendre les mécanismes essentiels d'une transaction Bitcoin. Le rapport est disponible dans ce dépôt.



\## Outils utilisés

GitHub, GitHub Desktop, éditeur de texte et ChatGPT (aide à la rédaction et à la structuration).

## Conclusion

Ce projet m'a permis de mieux comprendre le fonctionnement des transactions Bitcoin et leur validation sur la blockchain.
